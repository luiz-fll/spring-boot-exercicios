# Exercícios de Spring Boot

Exercícios de backend realizados com Spring Boot. Os exercícios loans, authentication, points-of-interest,
url-shortener, secure-password e cryptography foram disponibilizados no repositório 
[backend-br/desafios](https://github.com/backend-br/desafios), sob a licensa MIT.
O enunciados dos demais exercícios forma gerados com IA. 
Cada exercício possui uma pasta com um projeto Spring Boot e um enunciado (README.md).
